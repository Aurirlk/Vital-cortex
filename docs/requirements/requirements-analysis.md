# 智康云健康管理系统 - 需求分析文档

## 1. 项目概述

### 1.1 项目背景
智康云健康管理系统被一家医院收购，需要进行全面升级，包括：
- UI 重构（参考小红书风格）
- 新增论坛功能（整合到健康资讯模块）
- 新增真实医生预约系统
- 新增健康知识测验、健康商城、患者随访功能
- 新增商家端和医生端

### 1.2 项目目标
将智康云升级为医院级产品，满足结课报告 7 大模块要求。

## 2. 功能需求

### 2.1 用户端功能

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| 健康资讯 | 浏览、搜索、收藏健康文章，支持轮播图 | 高 |
| 论坛社区 | 发帖、回帖、点赞、收藏、关注、热榜、搜索、举报 | 高 |
| 医生预约 | 选择科室→选择医生→选择时间→确认预约 | 高 |
| 健康测验 | 题库浏览、在线答题、自动评分、成绩报告 | 高 |
| 健康商城 | 商品浏览、购物车、下单、模拟支付 | 高 |
| 患者随访 | 任务查看、打卡、记录查看 | 高 |
| AI 健康分析 | 6 种 AI 角色，支持联网搜索、知识库 RAG | 高 |
| 药品订阅 | 浏览药品信息，订阅关注的药品 | 中 |
| 个人中心 | 个人信息、统计、服务菜单、账号设置 | 中 |

### 2.2 管理端功能

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| 仪表盘 | 用户增长、健康记录等统计图表 | 高 |
| 用户管理 | 用户信息 CRUD | 高 |
| 资讯管理 | 健康文章 CRUD，支持轮播图和置顶 | 高 |
| 预约管理 | 科室、医生、排班、预约记录管理 | 高 |
| 测验管理 | 题库管理、试卷管理 | 高 |
| 商城管理 | 商品管理、订单管理、分类管理 | 高 |
| 随访管理 | 任务创建、指派、打卡记录查看 | 高 |
| AI 配置 | 多厂商切换，配置持久化 | 中 |

### 2.3 商家端功能

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| 商品管理 | 商品上下架、库存管理 | 高 |
| 订单管理 | 订单查询、状态管理 | 高 |
| 数据统计 | 销量、收入统计 | 中 |

### 2.4 医生端功能

| 功能模块 | 功能描述 | 优先级 |
|----------|----------|--------|
| 排班管理 | 排班设置、查看 | 高 |
| 预约管理 | 预约列表、确认/完成 | 高 |
| 就诊记录 | 填写主诉、诊断、医嘱 | 高 |
| 患者管理 | 患者列表、随访任务 | 中 |

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间 < 3 秒
- API 响应时间 < 500ms
- 支持 100+ 并发用户

### 3.2 安全需求
- JWT 认证
- 密码 BCrypt 加密
- API 权限控制

### 3.3 兼容性需求
- 支持 Chrome、Firefox、Safari、Edge 最新版
- 支持移动端响应式

## 5. 流程图

### 5.1 预约挂号流程
```
选择科室 -> 选择医生 -> 选择时间 -> 确认预约 -> 预约成功
                                      ↓
                                  取消预约 -> 号源释放
```

### 5.2 购物流程
```
浏览商品 -> 加入购物车 -> 选择地址 -> 创建订单 -> 模拟支付 -> 支付成功
```

### 5.3 测验流程
```
选择试卷 -> 开始答题 -> 提交试卷 -> 自动评分 -> 查看成绩
```

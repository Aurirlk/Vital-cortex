## 一句话结论

> **系统"看起来什么都有"，实际是「代码骨架齐全 + 数据空洞」+「33 条 SQL 随时会崩」。**

> - 36 个 Mapper / 265 条 SQL / 335 处端点映射看似完备（10-06 时分别为 41 / 284 / 250）
> - 但 **7 张表根本不存在**，调用即抛 `Table doesn't exist`

### 🔴 向量库 208/312 错位

实际路径 `cache/crm/vector_store/`（注意：`application.yml:86` 的 `crm.vectordb.store-path`；而 `crm_data/vector_store/` 是**空目录**）

```
collections.json   → doc_count: 312, dimension: 1536, collection: health_knowledge
documents.json     → 实际 312 个文档
vectors.bin        → 1,277,952 字节 = 1277952 / 4 / 1536 = 208.0 条向量
metadata.json      → deletedIds 31 个（[192, 1, 193-211, 183-188, 253, 189-191]）
```

**Bug 链**：`LocalVectorStoreImpl.java:94` 调 `readAll(docCount=312)` → `VectorBinaryStore` 内部 `Math.min(docCount, 文件可读条数)` = `min(312, 208)` = 208 → 但第 113 行 `for i < docCount` 构造 **312 条 documents** → `cosineSearchTopK` 用 208 向量配 312 文档下标 → **下标 208~311 的 104 篇永久不可召回，且向量与文档对应关系已错位**。

**修复方式**：`NewsController.java:94` 已有 `/news/rag/rebuild` 端点，跑一次即可。

## 九、DataAgent 迁移方案

### 9.1 关键事实（决定方案形态）

**`D:\Program\DataAgent` 是 Java 项目（阿里 spring-ai-alibaba/DataAgent，Apache 2.0，PR#629），不是 Python。**

| 能力 | 支持情况 |
|---|---|
| 自然语言 → SQL（NL2SQL） | ✅ 成熟。17 个 prompt 模板、MySQL 方言完整、7 种 JDBC 数据源 |
| **Neo4j / Cypher** | 🔴 **全仓 0 处引用，完全不支持**。`service/graph/` 是 Agent 编排状态图（StateGraph），不是图数据库 |

### 9.2 为什么不能"源码合并"

| 硬冲突 | 实测证据 | 能否绕过 |
|---|---|---|
| **WebFlux vs MVC 不可共存** | DataAgent **41 个文件含 `reactor.core`**；`util/FluxUtil.java` 21 处 reactive；`StreamLlmService`、`SessionEventPublisher`、`AgentApiKeyReactiveAuthenticationManager` 全是 reactive | **不能**。排除 webflux 依赖后这些文件**编译就过不了** |
| 改 WebFlux 会摧毁 ThreadLocal | 本项目 **11 个文件依赖 ThreadLocal**：`LocalThreadHolder`、`JwtInterceptor`、`ProtectorAspect`、`ToolContext`、`AiSessionContext`、`BaseReActAgent`、`StreamingReActAgent`、`UserChatController`、`CrmChatController`、`SeaChatWorkflow`、`DoctorWorkServiceImpl`；另有 26 处 `@Async`/线程池 | ❌ 直接破坏"医生端身份从 LocalThreadHolder 取"铁律。**单行道，不做** |
| Spring Security → 全站 401 | DataAgent 引 `spring-boot-starter-security` + `AgentApiKey*`；本项目用 `@Protector` 自定义鉴权 | 需全局放行，等于引入空转框架 |
| 依赖树污染 | hive-jdbc 3.1.3、ojdbc8、mssql-jdbc、DmJdbcDriver18、**commons-collections 3.2.1**、opentelemetry×4、milvus、es、druid | 部分可 exclusions，但 3.2.1 与现有 commons-lang3 冲突 |
| **Spring AI 1.1.2.2 × Boot 3.5.16** | 1.1.x baseline 是 Boot 3.4.x | 🔴 **未验证**。失败模式极差：`@ConditionalOnClass` 错配时不报错而是**静默不装配**，运行期才炸 |

**结论：DataAgent 11 万行代码里，我们需要的是 506 行 prompt 文本 + 约 700 行元数据查询逻辑（合计 1.2%）。其余是编排/reactive/16 张元数据表/Python 沙箱/MCP/7 方言 —— 全是负债。**

### 9.3 方案：资产摘取（零新依赖）

**A 组：直接复制资源**（Apache 2.0，需 NOTICE 标注来源）

从 `D:\Program\DataAgent\data-agent-management\src\main\resources\prompts\` 复制 7 个到 `personal-health-api/src/main/resources/ai-prompts/`：
`new-sql-generate.txt`(79) · `query-enhancement.txt`(87) · `semantic-consistency.txt`(80) · `sql-error-fixer.txt`(53) · `intent-recognition.txt`(96) · `evidence-query-rewrite.txt`(66) · `mix-selector.txt`(45) = **506 行**

**B 组：重写移植**（5 个新 Java 文件，零框架依赖）

| 新文件 | 参考源 | 行数 | 重写要点 |
|---|---|---|---|
| `core/nl2sql/JdbcSchemaIntrospector.java` | `MysqlJdbcDdl.java`(249) | ~180 | 丢弃 `Ddl`/`AbstractJdbcDdl`/`AccessorFactory`/自建连接池，**改用现有 DataSource**；保留 `information_schema` 查询、库名正则 `":\\d+/([^/?&]+)"` |
| `core/nl2sql/Nl2SqlSchemaService.java` | `SchemaServiceImpl.java`(521) | ~220 | 丢弃 `AgentVectorStoreService`/`Document`/`FilterExpressionBuilder`（**Spring AI 依赖主要来源**） |
| `core/nl2sql/Nl2SqlPromptBuilder.java` | `PromptHelper.java`(337) | ~120 | 自实现 `{}` 占位符替换替代 Spring AI 的 `PromptTemplate`（~25 行） |

**总计：830 行新 Java + 506 行复制资源，5 个新文件，零新 Maven 依赖，pom.xml 不动。**

### 9.4 DataAgent 的 NL2SQL 安全模型 vs 我们的要求

| 项 | DataAgent | 本方案 |
|---|---|---|
| 只读防护 | 🔴 **仅 prompt 软约束**（`new-sql-generate.txt:39-40`） | 参数化查询（无 SQL 产出）+ 硬校验 |
| 行数限制 | `setMaxRows(1000)` | `setMaxRows(200)` |
| 超时 | 30s | 10s |
| 租户隔离 | 🔴 **无** | `TenantSqlRewriter` 无条件覆写 + `ai_ro` 只读账号 |

**🔴 租户隔离核心设计：重写而非校验**

不要"检查 SQL 里有没有正确的 user_id"——LLM 可写 `WHERE user_id=3 OR 1=1`，检查永远追不上花样。正确做法是**无条件覆写**：

```
LLM 生成 SQL
 → ① MySqlAiSqlGuard.validate(sql)         词法校验（新建，不改 SqlGuard）
 → ② TenantSqlRewriter.rewrite(sql, ...)   删掉所有 user_id/patient_id/doctor_id 谓词
                                     无条件追加 AND user_id = :__tenantUserId
 → ③ NamedParameterJdbcTemplate 绑定真值    真值从 ThreadLocal 取，从不来自 SQL 文本
 → ④ ai_ro 只读账号执行，setMaxRows(200) + setQueryTimeout(10)
```
